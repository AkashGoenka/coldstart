# app/controllers/authenticated_admin_controller.rb

The admin gate is `before_action :authenticate_admin!`, which is not defined in the repo: it is the Devise helper generated by `devise_for :admins` in config/routes.rb. Every Admin:: controller in app/controllers/admin/ inherits it by subclassing this class, and no subclass in the repo skips it. Devise's own Admin::SessionsController and Admins::OmniauthCallbacksController inherit from Devise controllers rather than this one, so the sign-in and SAML callback endpoints are not behind it. Any new admin controller that subclasses ApplicationController directly gets no admin check.
